About Semantic HTML

Semantic elements clearly describe their meaning in a human- and machine-readable way. For example, <article> represents independent content, and <nav> defines navigation links.

Using semantic tags makes a web page easier to understand, accessible, and SEO-friendly.

Quick Notes

  • Use <header> for page or section headings.
  • Use <section> to group related content.
  • Use <article> for standalone posts or news.
  • Use <aside> for side information or ads.
  • Use <footer> for bottom page info.
